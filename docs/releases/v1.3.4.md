# 1.3.4：在线封面修复与完整发布同步

**当前推荐版本，Windows x64 便携单文件，免安装。**

## 本轮修复

- 修复收藏页在线收藏、在线历史和追更的封面空白。接口提供空封面字段时，按作品编号生成正确图片地址，同时保留可信来源检查。
- 补充三个在线分类的封面实际解码与显示检查。真实窗口已验证在线收藏、20 条在线历史、追更以及滚动和刷新。
- 同步 README、各版本中文发布说明及版本下载入口。发布附件提供 `SHA256SUMS.txt`；最新发布流程包含完整自动测试、类型检查、包内依赖检查和实际 EXE 隔离回归。

## 下载、校验与升级

下载本页 `JMComic.Desktop.Portable.1.3.4.exe` 和 `SHA256SUMS.txt`。校验命令：

```powershell
Get-FileHash -LiteralPath '.\JMComic.Desktop.Portable.1.3.4.exe' -Algorithm SHA256
```

结果应与同一 Release 的校验文件一致。GitHub 构建与本地构建可能得到不同文件哈希，不混用两套校验值。

正常退出旧版，把新 EXE 放在原目录，保留同级 `JMComicData` 和漫画下载文件。记住会话采用本机系统加密，迁移电脑可能需要重新登录，密码不落盘。

## 已知边界

- 在线功能依赖站点，临时网络或接口异常会在对应功能中提示。
- 远端注销未确认时会明确提示；本机仍清除会话。作品点赞不可撤回，服务端跨会话状态可能不一致。
- PDF 下载位置需要支持硬链接（如 NTFS），超大图片可能需要使用图片下载。
