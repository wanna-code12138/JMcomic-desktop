# 1.3.3：在线资料库与账户资料管理

Windows x64 便携版。此版本为阶段归档，**有已知的在线收藏、历史和追更封面空白问题，已在 [1.3.4](https://github.com/wanna-code12138/JMcomic-desktop/releases/tag/v1.3.4) 修复，推荐下载 1.3.4。**

## 本轮更新

- 在线收藏夹支持创建、改名、作品移动及删除已确认的空夹，保护默认收藏夹和非空夹。
- 新增收藏标签管理；针对服务端繁简转换，修复新建标签无法按显示名取消的问题。
- 在线历史支持二次确认后删除单条记录，本地精确阅读进度保持独立。
- 支持有限编辑昵称、简介和网站，只提交改动字段并回读确认结果。
- 启动恢复遇到临时网络失败时，保留加密会话并提供重试入口。
- 包含此前的评论互动、账户活动、阅读标签、PDF 下载和外观优化。

## 下载与升级

本页 EXE 附有 `SHA256SUMS.txt`，可使用 PowerShell `Get-FileHash -Algorithm SHA256` 校验。正常退出旧版后，将新 EXE 放在原目录，保留 `JMComicData` 和下载文件。

部分旧标签可能缺少服务器可接受的原始名称；软件会保留失败提示，不猜测名称连续删除。点赞状态及远端会话撤销仍受服务端行为影响。
