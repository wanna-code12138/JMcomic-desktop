# 1.1.0：阅读工作区与 PDF 下载

Windows x64 便携版。此版本按原提交补发归档，当前推荐使用 [1.3.4](https://github.com/wanna-code12138/JMcomic-desktop/releases/tag/v1.3.4)。

## 本轮更新

- 新增浏览器式阅读标签：独立起始页、新建、拖动排序、固定、重命名、批量关闭、最近关闭恢复、搜索和快捷键。
- 可选恢复上次工作区与阅读位置；浏览和阅读分栏支持拖动及键盘调整。
- 下载可选择逐张图片或合并 PDF。PDF 支持章节书签、进度、取消、重试和断点补页，完成文件放在下载根目录。
- 新增独立的动画与 GPU 硬件加速开关，统一浅深主题、应用图标、过渡和窄栏布局。
- 修复单篇作品详情加载失败、无效详情缓存、隐藏阅读侧栏后的滚动位置及下载状态竞态。
- 同时包含此前 1.0.6 开发节点的匿名 API 内容网关、分层回退、图片缓存与优先级、推荐偏好、离线阅读和 CBZ 导出。1.0.6 未独立发布。

## 下载与升级

下载本页 EXE 和 `SHA256SUMS.txt`，用 PowerShell `Get-FileHash -Algorithm SHA256` 校验文件。正常退出旧版后，将新 EXE 放在原目录，保留同级 `JMComicData` 和漫画下载文件。

PDF 下载位置须支持硬链接（如 NTFS）；超大图片可能提示改用图片下载。本版没有 1.3 系列的评论和在线账户功能。
