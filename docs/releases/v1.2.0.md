# 1.2.0：设置分组与外观精修

Windows x64 便携版。此版本按原提交补发归档，当前推荐使用 [1.3.4](https://github.com/wanna-code12138/JMcomic-desktop/releases/tag/v1.3.4)。

## 本轮更新

- 设置页采用分组清单，保留原有顺序和说明；窄栏下开关与文字独立排列，主题选项随宽度换行。
- 统一 Fluent 控件及自定义表面的颜色、字号、圆角和边界；浅色采用中性底色，深色延续石墨色。
- 修复深色详情标签的对比度，统一收藏图标和品牌文字颜色。
- 整理浏览页标签、空态、详情文字层级、下载元信息、新标签页和阅读工具的外观；诊断数字右对齐。
- 延续 1.1.0 的阅读标签、PDF 下载和动画机制，保留阅读画布及工作区布局行为。

## 下载与升级

下载本页 EXE 和 `SHA256SUMS.txt`，用 PowerShell `Get-FileHash -Algorithm SHA256` 校验文件。正常退出旧版后，将新 EXE 放在原目录，保留同级 `JMComicData` 和漫画下载文件。

本版没有 1.3 系列的评论和在线账户功能。
