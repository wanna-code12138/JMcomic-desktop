# 1.3.1：评论与在线账户核心

Windows x64 便携版。此版本为阶段归档，**有已知的在线收藏、历史和追更封面空白问题，已在 [1.3.4](https://github.com/wanna-code12138/JMcomic-desktop/releases/tag/v1.3.4) 修复，推荐下载 1.3.4。**

## 本轮更新

- 详情页新增匿名评论分页、回复展开、剧透遮挡、局部重试和缓存。
- 新增在线账户入口：登录、加密记住会话、重启恢复、重新验证与退出清理，不保存密码。
- 收藏页区分本地和在线收藏、历史，新增追更；详情页支持在线收藏与追更。
- 新增账户概览与通知，通知需明确点击后才标记已读。
- 账户使用独立内存会话，隔离旧请求响应；收藏和追更操作回读确认，结果未知时提示刷新，避免重复提交。

1.3.0 为设计阶段，核心功能首次交付版本是 1.3.1。

## 下载与升级

本页 EXE 附有 `SHA256SUMS.txt`，可使用 PowerShell `Get-FileHash -Algorithm SHA256` 校验。正常退出旧版后，将新 EXE 放在原目录，保留 `JMComicData` 和下载文件。

会话使用本机系统加密，迁移电脑后可能需要重新登录。在线功能依赖服务端；本地收藏和阅读进度仍可独立使用。
