## 验证纪律

工程行为先新增有意义测试并实际看到红灯，再实现与验证。复用 `npm test`、`npm run typecheck`、`npm run build` 及真实 Electron `scripts/reader-smoke.cjs` 夹具，新增场景沿用隔离数据与合成网络。每步记录真实命令 / 结果，当前未完成的项目不使用历史成绩。测试的 tsx 加载器在受限环境存在 `uv_os_get_passwd` 错误，按正常权限流程运行，不能把它记为产品红灯。

PDF 在依赖安装前查现有环境、官方来源、传递依赖与大小。大文档逐页读取，生成工作与渲染进程分离。打包复用项目 Electron 和已验证官方工具缓存，避免重复大下载。实际 EXE 必须直接启动测试；合成网络与实网证据分别报告。
