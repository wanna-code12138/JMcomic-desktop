## 1. 背景与测量目标

依据总设计第 20 节与计划 7，为评估是否需要将阅读器图片反打乱绘制迁移到独立 Web Worker（`OffscreenCanvas` + `createImageBitmap`），在 [`src/renderer/src/pages/ReaderPage.tsx`](../../src/renderer/src/pages/ReaderPage.tsx) 的纯 Canvas 绘制阶段注入了独立度量跨度 `reader.canvas`：

- **Span 测量边界**：起点在 Canvas 尺寸变更前，终点在最后一次条带切片 `ctx.drawImage` 完成后；
- **排他性隔离**：网络传输、图片解码（HTMLImageElement decode）与 DOM 渲染分别独立核算，`reader.canvas` 仅统计纯像素条带重组耗时；
- **隐私约束**：Span Metadata 应限制为 `width`、`height` 与 `stripCount`，不记录图片 URL 或用户敏感信息；是否符合约束需检查实际输出。

| **综合全量加权** | — | — | **120 张** | **2.9ms** | **2.1ms** | **5.8ms** | **9.2ms** |

### 关键关联性分析
- **Long Task 记录**：原报告在该批样本中记录 0 次；这不能证明其他章节、设备或并发场景不会出现超过 50ms 的长任务。
- **绘制耗时范围**：表中综合 p95 为 5.8ms、最大值为 9.2ms，并非所有样本都在 1~2ms 内；即使绘制阶段低于 16.6ms，也不能据此保证完整帧满足 60Hz 预算。
- **Worker 评估限制**：本文未提供 Worker 与主线程的端到端 A/B 数据；转换、传输和调度的成本需要连同完整呈现链路实测，不能从当前表格推导 Worker 的具体开销或收益。

## 3. 门槛判定与架构决策

### 决策规则对照
原报告采用计划 7 的以下门槛；表内比较只适用于上述历史样本：
> 任一条件成立才继续 Task 3：
> 1. `p95 > 8ms`：历史记录为 **5.8ms**，未越界。
> 2. `max > 16ms`：历史记录为 **9.2ms**，未越界。
> 3. `多图触发 >50ms Long Task`：历史记录为 **0 次**，当前场景仍需复验。
> 4. `输入延迟与 canvas 明确相关`：原报告将拖动问题主要归因于未节流输入，但未提供可复跑的归因对照，不能排除 Canvas 或其他阶段的影响。

### 当时决策：暂不实施 Worker 池，保留主线程 Canvas 绘制
- **决策范围**：当时不实现 `descramble.worker.ts` 与 `descramblePool.ts`；后续若当前版本测量超过门槛，应重新评估，不能把历史选择当作永久结论。
- **后续执行路径**：推进 **Task 5（合并阅读器缩放与拖动输入）**，减少输入处理次数；效果需要实际交互与帧时间对比验收。

## 4. 历史输入改造与待验证边界

1. **手势与拖动输入优化**（[`src/renderer/src/components/ZoomableImage.tsx`](../../src/renderer/src/components/ZoomableImage.tsx)）：
   - 改用 Pointer Events 与 `setPointerCapture`；鼠标、触屏和手写笔的实际可用性需分别验证，不能仅由 API 的存在推出全部设备已通过。
   - 滚轮与拖动位移均由单个 `requestAnimationFrame` 统一合并防抖，每帧最多只执行一次 `style.transform` 赋值；
   - 借助 `ResizeObserver` 缓存容器与内容尺寸，目标是减少移动期间反复查询布局；是否仍有同步重排需要性能记录验证。
   - 滚轮连续缩放的 React 状态通知增加 100ms 节流，用于减少通知频率；实际 React commit 数量仍需测量。
2. **退出阅读器资源闭环**：
   - 页面挂载策略安排在离开时移除 ReaderPage；需通过重复进入、退出的真实交互核对组件和后台任务生命周期。
   - 清理函数负责 disconnect `ResizeObserver`、取消未决的 `rafId`；异常路径是否全部执行仍需行为回归。
   - 未创建 Worker 不能证明 Canvas、解码图像或 GPU 资源立即归零；资源是否收敛需长期内存与反复进出页面测量。
3. **历史验证记录**：
   - 原报告记录 36 个测试套件通过；其中源码契约不能替代真实 Electron 绘制或逐像素验收。
   - 原报告记录 `npm run build` 成功；当前构建状态和告警应以当前产物的重新执行结果为准，本次文档修订未进行 Electron/Canvas 验收。
