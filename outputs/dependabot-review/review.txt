Dependabot 的作用
GitHub 根据 .github/dependabot.yml 自动提出依赖版本更新。
本项目每周分别检查 npm 和 GitHub Actions，每类最多打开 5 条版本更新 PR。
此次 7 条为 5 条 npm 更新和 2 条 Actions 更新，不应把 PR 数量解读成漏洞数量。
安全告警 API 返回 403，本记录没有据此判断仓库是否存在其他安全漏洞。
