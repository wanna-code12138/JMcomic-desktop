## 本版完成内容

| 需求 | 最终行为 |
| --- | --- |
| 浏览器式阅读标签 | 加号/快捷键新建、X/中键关闭、拖放排序、固定分区、重命名/原标题、关闭其他/右侧/未固定项、最近关闭恢复、溢出列表搜索；最多 100 个标签，关闭栈 20 项 |
| 新标签页 | 搜索标题或 JM 号、继续阅读、收藏/历史/离线入口、最近关闭；空标签不加载图片 |
| 保存与恢复 | 切换/关闭先保存，失败留在当前阅读并可重试；标签变更串行；可选冷启动恢复名称/顺序/固定/活动标签和阅读位置；后台只保存元数据 |
| 布局与缺陷 | 设置和诊断滚动容器始终占满所在栏，内容在内部限宽；侧栏隐藏、最后关闭恢复用户导航选择；分隔条支持拖动、键盘和双击复位 |
| 动画 | 页面、标签增删/切换、分栏、导航、阅读工具/目录、菜单/弹窗、下载浮层与状态反馈；主要使用短 opacity/transform 过渡；退出内容立即 inert |
| 视觉 | GPT Image 生成 UI 构图及正式书页/书签图标；浅深色语义表面、间距、响应式卡片统一；操作控件仍使用清晰可缩放的 Fluent 图标 |
| 两个开关 | 设置→阅读与交互：动画即时生效，尊重系统减少动态效果；GPU 独立保存、重启应用，不限定显卡厂商，并展示实际合成状态 |
| 下载格式 | 未指定默认则每次询问；可记住图片/PDF，入口仍可临时选择；一次选中的多个章节按顺序合为一个带书签 PDF，直接落下载根目录；图片沿用漫画/章节目录 |
| PDF 可靠性 | 持久化任务、取消/重试、断点补页、独立线程逐页生成、校验后发布、同名编号、崩溃恢复/暂存清理；个人数据导入/导出/清除覆盖新增状态 |

兼容性取舍：使用 Chromium 默认兼容策略，未使用强行忽略驱动屏蔽的参数。GPU 不可用时可以软件渲染。图片解码完成即显示，避免虚拟滚动时反复给每张长图添加淡入；主要动效落在页面/阅读会话与轻量控件外壳。

### 动画 / GPU 资源矩阵

最终构建，每组执行 **50 次新建/关闭/隐藏/恢复**，结束静置 **30 秒**。每组末态均为 **1 个活动阅读器、1 个标签、6 个图片/Canvas节点、0 个运行中动画**。

| GPU | 动画 | 合成器 | 全进程私有内存合计抽样最大值 | 末态 renderer JS heap |
| --- | --- | --- | ---: | ---: |
| 关 | 关 | disabled_software | 350.59 MiB | 14.50 MiB |
| 关 | 开 | disabled_software | 336.69 MiB | 14.50 MiB |
| 开 | 关 | enabled | 594.00 MiB | 16.31 MiB |
| 开 | 开 | enabled | 582.25 MiB | 14.50 MiB |

原始样本：[关/关](reader-qa/110-resource-50-gpu-off-motion-off/resource-matrix.json)、[关/开](reader-qa/110-resource-50-gpu-off-motion-on/resource-matrix.json)、[开/关](reader-qa/110-resource-50-gpu-on-motion-off/resource-matrix.json)、[开/开](reader-qa/110-resource-50-gpu-on-motion-on/resource-matrix.json)。

这些是本机隐藏 Electron 窗口与合成素材的测量，包含夹具及所有测试应用子进程，不是显存、净动画开销或真实呈现 FPS。内存样本有 GC/分配噪声，不能据表中较小数值推断“开动画更省内存”。未声称达到设计中可见窗口 p95 首反馈/帧间隔目标，也未完成所有厂商驱动或长时间泄漏实测。

## 回归证据、边界与流程记录

- 实际失败后修复覆盖标签状态/保存竞态、PDF 入队及取消/重试/删除/恢复、个人数据停止顺序、导航滚动容器、菜单退出、下载进度过渡、遮挡提示、延迟焦点与 GPU off 隐藏窗口动画残留。相关失败日志与 red 结果保留；系统限制导致的 tsx `uv_os_get_passwd` 不是产品失败，使用正常提升权限复验。
- 流程偏差明确记录：WebP 的 `forcePng` 分支实现早于它专属的 Chromium 格式测试，本次已补实际像素验证，不能把它报告成严格测试先行。图标、调色、排版等视觉变更以产物目检和构建验证。标签条瞬时竖滚动条按截图修复，稳态回归本来就通过，未将该稳态测试伪称失败测试。
- 拖放已验证 DOM drag/drop 事件及最终排序，键盘/按钮使用真实 Electron 输入；未把 DOM 事件等同 Windows 原生拖动录屏。跨窗口分离、标签组不在本版范围。
- PDF 安全发布要求目标文件系统支持硬链接（例如 NTFS）；不支持时明确失败并保留重试任务。单张 PNG 16,777,216 像素保护上限，超限提示改用图片下载。worker 的 256 MiB V8 heap 限额不等于进程总内存上限。
- 网络验收使用受控合成内容；本轮没有把真实站点 CDN 吞吐量、登录/站点状态或所有 EXIF 方向当作已测。
- 测试使用隔离用户数据，没有读取或删除用户个人漫画。发布目录被 Git 忽略；源码、正式图标、文档与必要验证证据提交到当前任务分支。
